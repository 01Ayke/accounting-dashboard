## Lancer le conteneur MySQL avec Docker Compose
```code
docker-compose up -d
```

## Prérequis
Assurez-vous d'avoir Docker et Docker Compose installés sur votre machine.
Pensez à activer la virtualisation dans le BIOS si ce n'est pas déjà fait.

## Script de lancement
Un script PowerShell `launch.ps1` pour les utilisateurs de Windows est fourni pour faciliter le processus de lancement.
Un script bash `launch.sh` est également disponible pour les utilisateurs de systèmes Unix/Linux.
